# CRUD de Productos

## Funcionalidades
- Crear productos
- Consultar productos
- Actualizar productos
- Eliminar productos

Cada producto tiene: ID único, nombre, descripción, precio y cantidad disponible.
Los datos se guardan en una lista en memoria.

## Cómo ejecutar el programa
    python crud_productos.py

## Cómo ejecutar las pruebas
    python -m unittest -v
